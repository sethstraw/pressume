pressume

Render polished, verified resumes and CVs from portable Markdown.

One Markdown file becomes a PDF and plain text, with a Word file on request. Then pressume reopens each file and checks what it contains.

Quick start Source on GitHub

Why it exists

A PDF can look fine while its text extracts in the wrong order, a link stops working, a title gets shortened, or a page overflows. Converting the file is half the job. pressume renders the document and then checks the output it really wrote.

Render

Pandoc and Typst turn Markdown into PDF and TXT by default, with DOCX on request. Three themes, three spacing densities, US Letter or A4.

Verify

Page targets, text from two independent extractors, exact wording, links, metadata, tagged accessibility structure, and spacing around headings.

Stay local

Everything runs on local files. A failed render leaves your existing files untouched.

What is checked

Every render ends with a report. Below is an excerpt of the real report for the bundled starter resume. The warning is expected: no page target was set.

PASSdocument contract
WARNpdf: page count1 page(s), no target set
PASSats: name leads document
PASSats: section headings5 sections in order
PASSats: consistent dates5 long-style dates
PASSpdf: accessibility structuretagged=True, language=en-US
PASSpdf: hyperlinks3 embedded link(s)
PASSpdf: visual relationships22 line clearance(s) clear
PASSpdf: independent extraction100.00% character agreement, 100.00% coverage, 100.00% token-boundary agreement; pypdf=190 words, poppler=190 words

pressume does not score a resume, tailor its content, or claim compatibility with every applicant-tracking system. Its checks cover specific, observable properties. Read the finished document before you send it.

Three themes

The same starter resume in each bundled theme. Preview one without changing configuration: pressume preview Resume.md --theme traditional --open.

Quick start

Install with uv. pressume runs on Python 3.10 or newer on macOS, Linux, and Windows.

uv tool install git+https://github.com/sethstraw/pressume.git
mkdir my-resume
cd my-resume
pressume new resume
pressume preview Resume.md --open
pressume render

The README covers configuration, cover letters, every command, and the full list of checks.
